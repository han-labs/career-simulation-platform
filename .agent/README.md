# Career Simulation Platform `.agent` knowledge base

This tracked folder keeps humans and AI coding agents aligned with the proposal, architecture, team scope, quality gates, and report evidence.

Read in this order:

1. `AGENTS.md` - binding workflow and scope rules.
2. `PROJECT_CONTEXT.md` - product purpose, actors, MVP, business rules, and architecture.
3. `TASKS.md` - ownership, dependencies, and Definition of Done.
4. `DESIGN.md` - visual and interaction system.
5. Relevant files in `rules/`.
6. A copied template in `templates/` for the feature being implemented.

Folder map:

- `plans/` - approved feature and foundation plans.
- `references/` - the supplied proposal, architecture image, and source index.
- `reports/` - implementation/evidence audits, not marketing summaries.
- `rules/` - architecture, GRASP, facade, AI, testing, report, security, and data rules.
- `templates/` - repeatable plan, trace, AI log, and report-update formats.

Never store `.env`, secrets, private student data, unrestricted model traces, or unlicensed third-party task content here.
