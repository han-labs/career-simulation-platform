# External Data and Research Rules

## The Forage reference boundary

Allowed without copying content:

- study public navigation, discovery, filters, metadata, progression, and reflection patterns;
- document high-level product concepts in your own words;
- create original tasks inspired by real job responsibility categories.

Not allowed without explicit permission/license review:

- copying employer task descriptions, files, model answers, certificates, branding, screenshots, or datasets;
- crawling behind login or bypassing rate limits/technical controls;
- republishing scraped content;
- presenting The Forage or an employer as a project partner.

## Source record

Every external dataset/content source must record:

```text
Source URL:
Publisher:
Retrieved date:
License/terms:
Permitted project use:
Fields/content used:
Transformations:
Reviewer:
Removal/update procedure:
```

If licensing or provenance is unclear, use synthetic/original content until the team approves the source.
