AI Agent Design · Governed Principles

Syn AI Agent: Trợ lý Định hướng có Kiểm soát

Syn được xây dựng theo mô hình Governed Hybrid AI Agent. Syn không phải một chatbot wrapper đơn thuần mà tuân thủ nghiêm ngặt các quy tắc an toàn dữ liệu, khôi phục sự cố mềm dẻo (Fallback) và không bao giờ tự ý phán quyết nghề nghiệp hay sửa đổi điểm số khách quan.

Rule-First Server Chấm Điểm 100%
0 Token Quick Actions Deterministic
Isolated LLM Không Query PostgreSQL
100% Safe Fail-Safe Multi-tier Fallback
1

1. Rule-First & Deterministic Policy

AI tuyệt đối không được tự ý tính toán hay thay đổi điểm số RIASEC hoặc kết quả bài tập Simulation. Mọi score đều do thuật toán Server tự chấm 100%. Syn chỉ làm nhiệm vụ diễn giải (Interpretation) dữ liệu đã có.

2

2. Hybrid Token Optimization (0 Token Quick Actions)

4 câu lệnh mẫu thao tác nhanh (Understand my interests, Review latest result, Find evidence gaps, Draft a next-step plan) chạy 100% bằng mã Java thuần phía Server $\rightarrow$ 0 tốn token LLM và phản hồi tức thì.

3

3. Context Minimization & Privacy Isolation

LLM không có quyền truy cập trực tiếp vào Database PostgreSQL. Backend làm "màng lọc": chỉ đóng gói dữ liệu rút gọn (Top 3 Signals, Skills, Results). Email, Mật khẩu, ID tài khoản, Đáp án thô bị loại bỏ hoàn toàn.

4

4. Multi-tier Fallback Strategy (Không Bao Giờ Sập)

Backend luôn tạo trước một bản Phản hồi Chuẩn hóa (Standard Reply) dự phòng. Nếu gọi Gemini/OpenAI bị đứt mạng, timeout (8s), hoặc sai JSON Schema $\rightarrow$ Trả về bản Standard Reply mà giao diện không bị sập.

Hướng dẫn Cấu hình & Kiểm thử Cơ chế Fallback

Các lệnh terminal giúp bạn cấu hình biến môi trường, cấp quyền consent AI và kiểm thử khả năng chịu lỗi (Fallback) của Syn Agent.

1. Cấu hình biến môi trường (.env) cho Gemini Provider 
AI_PROVIDER=gemini
GEMINI_API_KEY=YOUR_PRIVATE_GEMINI_KEY
GEMINI_MODEL=gemini-3.5-flash-lite
LOCAL_DEMO_MODE=true
LOCAL_DEMO_EMAIL=student@demo.com
2. Lệnh SQL cấp quyền Consent AI cho Student Demo trong Database 
docker compose exec -T postgres psql -U career_sim -d career_simulation -c \
"UPDATE student_profiles SET consented_to_ai_at = COALESCE(consented_to_ai_at, CURRENT_TIMESTAMP) \
 WHERE user_id = (SELECT id FROM app_users WHERE email = 'student@demo.com' AND role = 'STUDENT');"
3. Lệnh Thử nghiệm Fallback (Cố tình nhập sai Gemini Key để test Fallback) 
# Bước A: Đổi GEMINI_API_KEY=INVALID_KEY_TEST trong .env
# Bước B: Khởi động lại Backend service
docker compose restart backend

# Bước C: Gõ câu hỏi tự do bất kỳ trên Syn Widget
# Kết quả mong đợi: Syn vẫn phản hồi mượt mà với nhãn "Standard guidance"
