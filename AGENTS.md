# Career Simulation Platform Agent Entry Point

Before making changes, read these files in order:

1. `.agent/AGENTS.md`
2. `.agent/PROJECT_CONTEXT.md`
3. `.agent/TASKS.md`
4. `.agent/DESIGN.md`
5. The relevant files under `.agent/rules/`

Then follow the current [requirements index](docs/requirements/README.md) and the
official [team assignments](docs/TEAM_ASSIGNMENTS.md) for the selected UC.

Source authority has distinct purposes: the current report/CORRECTED handoff owns
the **10 selected US / 16 UC catalogue**; frozen Baseline v1 + DR1–DR2 own approved
business rules; P1–P6/V22 code, API contracts and tests establish implementation
state. `.agent` owns the development workflow, not a competing requirements set.
Record discrepancies in [report/code alignment](docs/requirements/REPORT_CODE_ALIGNMENT_2026-10-22.md).
Do not silently renumber catalogues, expand supplementary/deferred scope, or
reimplement P1–P6. Read the matching UC, AC and relevant architecture/API/rules only.
