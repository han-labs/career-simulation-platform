Technical Story

US-01: RIASEC Assessment

Hoàn thành bài đánh giá nghề nghiệp định hướng Holland (Frontend Local State)

● Trạng thái: Đang triển khai (Draft) Người phụ trách: Võ Nguyễn Ngọc Bích

1. Phạm vi & Mục tiêu (Scope)

Cung cấp cho sinh viên một giao diện làm bài test RIASEC, lưu trạng thái bài làm và tính toán kết quả nội bộ tại Frontend, chuẩn bị nền tảng trước khi tích hợp với Backend API.

  • Bắt đầu, tiếp tục (resume) và nộp bài đánh giá.
  • Hệ thống điểm dựa trên scale chuẩn, map tương ứng với 6 chỉ số RIASEC (R, I, A, S, E, C).
  • Hiển thị biểu đồ kết quả điểm số và chỉ ra xu hướng nổi bật nhất.
  • Lưu ý: Hiện tại TẤT CẢ logic tính điểm và state lưu trữ (LocalStorage) đang chạy trực tiếp ở Frontend. Việc gọi API lưu kết quả sẽ bị loại trừ ở chặng này.

2. Luồng thực thi chi tiết (E2E Flow) & Truy vết Code

Dưới đây là luồng thực thi chi tiết đính kèm mã nguồn từ lúc khởi động web, đi qua trang chủ (Landing Page), đến lúc hoàn thành bài test (US-01).

const [simulations, setSimulations] = useState(fallbackSimulations)

useEffect(() => {
  getPublishedSimulations() // Hàm gọi API fetch dữ liệu (/api/v1/simulations/published)

      setCatalogStatus('ready')

    .catch(() => {
      setCatalogStatus('fallback') // Server sập -> Giữ nguyên fallbackSimulations

4
Bắt đầu làm test (AssessmentPage.jsx -> useAssessment.js)

Khi người dùng bấm "Start", hàm handleStartOrResume kích hoạt logic của Hook useAssessment để gọi Mock API tạo phiên làm bài mới và render form.

const { start, status } = useAssessment();
const [isTakingTest, setIsTakingTest] = useState(false);

const handleStartOrResume = () => {
  if (status === 'intro') {
    start(); // Gửi POST /api/v1/assessments/attempts, đổi status 'in_progress'
  }
  setIsTakingTest(true); // Mở khóa UI Render AssessmentForm
}

Lưu trạng thái chọn đáp án (AssessmentForm.jsx -> useAssessment.js)

Form map qua từng thẻ câu hỏi. Khi chọn scale (1-5), callback setAnswer lưu vào state cục bộ, sau đó useEffect lưu xuống LocalStorage tự động lưu bài (Autosave).

// Trong useAssessment.js (Hook)
const setAnswer = useCallback((questionId, value) => {
  setState(prev => ({
    ...prev,
    answers: { ...prev.answers, [questionId]: value }
  }))
}, [])

// Autosave khi state thay đổi
useEffect(() => {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(state))
}, [state])

Xác nhận nộp bài & Validate (AssessmentForm.jsx)

Khi click "Submit", hàm kiểm tra số lượng câu đã trả lời. Nếu thiếu, tìm câu đầu tiên chưa làm (Dùng element ID) và cuộn chuột mượt mà tới đó.

const handleSubmit = (e) => {
  e.preventDefault()
  if (answeredCount < totalCount) {
    const missing = questions.filter(q => answers[q.id] === undefined).map(q => q.id)
    setErrorIds(missing)
    setError(`Please answer all questions before submitting.`)
    
    // Tự động scroll tới câu lỗi
    setTimeout(() => {
      const element = document.getElementById(`question-container-${missing[0]}`)
      if (element) element.scrollIntoView({ behavior: 'smooth', block: 'center' })
    }, 100)
    return
  }
  onSubmit() // Gửi kết quả qua useAssessment.js
}
7
Gọi Mock API & Trả kết quả (useAssessment.js)

Hàm submit() chuyển object đáp án thành array JSON. Gửi POST request. Nếu server trả về kết quả thành công, đổi state thành completed và render AssessmentResult.

const submit = useCallback(async () => {
  try {
    const answersPayload = Object.entries(state.answers).map(([qId, score]) => ({
      questionId: Number(qId), score
    }))

    // API POST lên hệ thống mock
    const res = await fetch(`/api/v1/assessments/attempts/${state.attemptId}/submit`, { 
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ answers: answersPayload })
    })
    const json = await res.json()
    
    // Thay đổi trạng thái UI
    setState(prev => ({ ...prev, status: 'completed', result: json.data }))
  } catch (err) { ... }
}, [state.answers, state.attemptId])

3. Thiết kế Kiến trúc Component (React)

AssessmentForm.jsx

Component cha. Chứa form submit, gọi validate và render danh sách các thẻ câu hỏi.

AssessmentQuestionCard.jsx

Component con. Chịu trách nhiệm hiển thị 1 câu hỏi cụ thể, nhận Props là nội dung câu hỏi và hàm callback set đáp án.

useAssessment.js

Custom Hook trừu tượng hóa logic quản lý state và tương tác với LocalStorage (Autosave).

riasecScorer.js

Module Javascript thuần túy (Không phải Component). Chứa thuật toán tính điểm độc lập với UI.
